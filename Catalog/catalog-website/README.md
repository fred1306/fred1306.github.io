# Disco Automotive Hardware — Product Catalog Website

A clean, searchable web catalog of **~7,095 products** from the Disco Automotive Hardware catalog (52 sections).

## How to open

**Just open `index.html` in your browser** — no server required.

All product data is embedded in `data.js`, so it works offline and when opened via double-click / `file://`.

## Features

- Sidebar grouped by: Core Hardware · Domestic OEM · Imports · Tools & Other
- Click a section → searchable, sortable product table
- Live filter + column sorting
- Export filtered view as CSV
- Responsive (desktop & mobile)
